# ふりかえりコーチ（認知の4点セット）

講義のあとのふりかえり（リフレクション）を、自分のAI（ChatGPT、Gemini、Claudeなど）と一緒に進めるための指示文です。京都工芸繊維大学「プロジェクトマネジメント入門」の受講者向けに作りました。

AIが「認知の4点セット」の問いを1つずつ出し、あなたの答えを受け止めながら進めます。最後に、受講記録に貼れる200字くらいのまとめを2つ出します。

- 意見：講義を、ほかの科目や活動にどう生かせると思うか
- 経験：その意見につながる経験や、知っていること
- 感情：その経験に結びついている気持ち
- 価値観：その気持ちから見えてくる、あなたが大切にしていること

## ダウンロード

| ファイル | 中身 | こんなときに |
|---|---|---|
| [furikaeri-prompt.txt](https://github.com/Knowledge-nudge/furikaeri-coach/releases/latest/download/furikaeri-prompt.txt) | 指示文を1枚にまとめたもの | どのAIでも使える。迷ったらこれ |
| [furikaeri-4point.zip](https://github.com/Knowledge-nudge/furikaeri-coach/releases/latest/download/furikaeri-4point.zip) | 「スキル」の形にしたもの（中身は同じ） | スキルを入れられるAIで使う |

リンクを押すとダウンロードが始まります。スマホでも使えます。

## クイックスタート

### 方法1：指示文を貼る（いちばん確実）

1. furikaeri-prompt.txt を開いて、中身を全部コピーする
2. AIで新しいチャットを開き、そのまま貼る
3. 1行目の【講義回】を、その日の回に書きかえる（例：第8回「シフトレフト」）
4. 送る。AIが最初の問いを出すので、答えていく

### 方法2：ファイルを渡して「スキルとして使えるようにして」と頼む

1. AIで新しいチャットを開き、furikaeri-prompt.txt（またはfurikaeri-4point.zip）を添付する
2. 次のように送る

```
添付したファイルを読み込んで、スキルとして使えるようにしてください。
その指示どおりのふりかえりコーチとして、第8回「シフトレフト」のふりかえりを始めてください。
```

AIによっては、zipの中を読めないことがあります。うまく始まらないときは、txtを添付するか、方法1にしてください。

### 方法3：スキルとして入れる（スキル機能のあるAI）

ClaudeやChatGPTなど、スキル（Skills）を入れる機能があるAIでは、furikaeri-4point.zipをそのままスキルとして登録できます。

1. AIの設定から、スキルを追加する画面を開く
2. furikaeri-4point.zip をアップロードして、オンにする
3. 新しいチャットで「第8回『シフトレフト』のふりかえりをしたい」と送る

スキル機能があるかどうか、どこにあるかは、AIの種類やプラン（無料・有料）によってちがいます。見つからないときは、方法1か方法2で同じことができます。

## 終わったら（受講記録の出し方）

最後に、AIが「要約1（エッジの効いたまとめ）」と「要約2（自分らしいことばのまとめ）」を出します。

1. 受講記録のフォームで、リフレクションの方法は「PM Mentor」を選ぶ
2. PM Mentorの欄に、このチャットの共有リンクと、要約のどちらか1つを貼る

共有リンクの出し方はAIによってちがいます（ChatGPTなら、画面右上の「共有」から）。共有リンクがうまく出せなくても、要約を貼ってあれば提出になります。

講義用のふりかえりコーチ（受付番号が出るもの）とちがい、こちらは受付番号が出ません。

## 気をつけること

- 名前、学生番号、連絡先は書かないでください。ほかの人がわかること（だれが・いつ・何をしたか）や、研究室の未発表のデータも、ぼかして書いてください
- 無料のAIは、設定によって、会話がAIの学習に使われることがあります。気になる人は、AIの設定で学習に使わないようにしてください（ChatGPTなら「データコントロール」）
- AIはまちがえることがあります。まとめは、自分のことばになっているか読み直してから貼ってください
- 気づきが1つことばになれば、ふりかえりは十分です。長く続けなくてかまいません

つらい気持ちになったときは、ひとりで抱えずに、大学の窓口や信頼できる人に話してください。

- からだの不調：保健管理センター 電話 075-724-7173

## ファイルの中身

```
furikaeri-prompt.txt        指示文を1枚にまとめたもの（下の3つと同じ中身）
furikaeri-4point/           スキルの形にしたもの（zipの中身）
├─ SKILL.md                 進め方（問いかけ、コメント、要約）
└─ references/
   ├─ rules.md              AIが守ること（個人情報、つらい気持ちへの対応など）
   └─ examples.md           4点セットの例と、回答例の候補
```
